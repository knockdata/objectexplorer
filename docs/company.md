## What we make

ObjectExplorer is a developer tool for data engineers. It is a desktop application, and an npm
package ([@knockdata/objectexplorer](https://www.npmjs.com/package/@knockdata/objectexplorer)), that
browses, previews and queries files in your own Amazon S3, Google Cloud Storage and Azure Blob
Storage accounts.

It runs on your own machine and talks to your cloud account directly. This website is where the
documentation and the installers live; it does not host your files, and your data never passes
through our servers. See [your data stays here](/privacy).
