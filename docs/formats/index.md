# Every format

More than 900 file extensions have a reader of their own, and dozens more kinds of file are told
by their content alone, whatever they are called — a browser's `History`, a WhatsApp export, a
PADS board saved as `.asc`. Every format below opens as itself rather than as bytes.

Which reader opens a file, its first bytes decide, not its name: a workbook renamed `.bin` still
opens as a workbook. A file cut short shows what it does hold, and one that really cannot be read
says why, in plain words, rather than showing nothing.

Every one of these parsers runs on your machine. Nothing is sent anywhere to be rendered — see
[your data stays here](/privacy).
