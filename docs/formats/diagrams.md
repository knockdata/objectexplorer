# Drawings and diagrams

`excalidraw`, and Mermaid's `mmd` `mermaid`

## Excalidraw

An `.excalidraw` file opens in a full drawing editor, hand-drawn look and all: shapes, arrows, text,
frames, and a laser pointer to present with. Frames step one at a time, with anything sequenced
inside a frame playing in order.

In a local folder, every change is saved back into the file as you draw.

## Mermaid

A Mermaid file opens as the diagram it describes, drawn by the app's own renderer rather than a
script fetched from somewhere. Fourteen kinds are drawn: flowchart, sequence, class, ER, Gantt, git
graph, journey, mind map, pie, quadrant, Sankey, timeline, XY chart and block.
