# Hex

<img src="/shot/hex.png" alt="The hex viewer: offsets, hex pairs and the ASCII column">

Any file, any size, straight to bytes. Offsets, hex pairs and the ASCII column, virtualized so a
multi-gigabyte object opens instantly instead of after a spinner — only the lines on screen are ever
fetched and drawn.

It is exactly what you need when a format is not recognized and the first 64 bytes decide what it is:
a magic number, a header, a footer at a known offset.

Hex is always available, for every object, from the toolbar.
