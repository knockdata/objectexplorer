# Promo credits

The film is built by `scripts/promo.mjs` from `promo/promo.html`:

```sh
node scripts/promo.mjs --preview   # one still per cut, into promo/preview
node scripts/promo.mjs             # the whole film, into docs/public/video
```

named here.
