## Today

Download 4 GB, or `aws s3 cp - | less`, and hope the tooling survives it.

## Here

Text and hex read the object in windows over HTTP Range with line checkpoints, so line nine million
opens as fast as line one. A recognised log export gets the log viewer instead: a timeline you zoom,
a resource tree, severity colouring.
