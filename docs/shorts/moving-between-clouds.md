## Today

Download every object to the laptop, then upload every object to the other provider: egress paid, a
day gone, and 200 GB sitting in `Downloads` until somebody remembers. A data engineer might reach for
`rclone` instead, which means a config file and a machine to run it on; nobody else on the team will.

## Here

Select, `⌘X`, walk to the other root, `⌘V`. Name clashes ask once — keep both, replace, skip, cancel —
before a byte moves, and `⌘Z` takes it back. A copy that stays inside one provider runs server-side
and never comes down at all.
